# Meeting Journey 0.5.2

- Settings now has a bounded card scroller above the bottom navigation, including the iPhone safe area. The duplicate floating companion is hidden on Settings; the header companion remains available.
- The tablet notebook uses a compact icon header and toolbar, smaller popovers, and a wider drawing pane. Drawing fills the available surface; ink in previously unused margins is saved as editable strokes. Rotation preserves stroke coordinates and does not enlarge saved paper by itself.
- Companion actions use cloud-shaped thought bubbles with a separate heart. The companion's name appears above the portrait.
- Drag the companion horizontally or vertically within the scene; all four keyboard arrows work too. Placement stays on this device. Background left/right swipes still navigate meeting parts.

Upload all contents of publish-node to the existing Node application root, restart Node, then open https://meetingjourney.com/refresh.html and tap Update app. Reopen the installed app; Settings shows 0.5.2.

No new artwork was generated. Interactive tablet/phone visual review remains outstanding; automated geometry, storage, rendering and packaged-server checks cover the changes.
