# Meeting Journey 0.5.3

The journey layout no longer assigns 100% of the available height to its card and then adds the meeting notice above it. The notice and card share the available area; Previous/Next have a reserved row above the main navigation. The main navigation owns the iPhone home-indicator padding.

The companion's feelings action is now just a heart, with an accessible label and a full touch target.

Upload all contents of publish-node, restart Node and open https://meetingjourney.com/refresh.html to update the installed app. Settings shows version 0.5.3. Personal notes and drawings remain on this device.
