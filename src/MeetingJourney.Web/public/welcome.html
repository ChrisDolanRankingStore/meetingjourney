Meeting Journey

A little support for following along

Meeting Journey helps people of all ages follow a meeting with a companion, optional prompts and a notebook for drawings and thoughts.

  1. Choose a companion.
  2. Choose the meeting and set your congregation’s days.
  3. Swipe between parts. Draw, write or just listen.

Install on iPad

Open meetingjourney.com in Safari. Tap Share, Add to Home Screen, then Open as Web App if offered.

Install on Android

Open the site in Chrome. Use the menu’s Install or Add to Home Screen action.

Before a meeting

In Settings, choose Save this meeting offline. Download official reading material separately in JW Library. Save a journal backup file from Settings regularly.

This is an independent companion. All personal content stays on the device.
