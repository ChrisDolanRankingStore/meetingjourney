# Meeting Journey web client

This is the separate React/TypeScript PWA client for Phase 1. It provides the accessible meeting shell, preference controls, journey map, optional clue mission and reusable Konva drawing surface backed by IndexedDB. It uses a bundled curated sample meeting when the API is unavailable.

Install dependencies and start the client after the API contract is agreed:

```powershell
npm.cmd install
npm.cmd run dev
```
